# 🚀 MyFinancialCRM - C# EĞİTİM KAMPI
Bu depo, Murat Yücedağ'ın eğitmenliğinde C# Eğitim Kampı sırasında geliştirilen finansal müşteri ilişkileri yönetimini (CRM) içerir. Aşağıda projeye dair teknik detayları bulabilirsiniz:

# 📍 MyFinancialCRM
Bu proje, Windows Forms ve Entity Framework kullanılarak temel veritabanı işlemlerini öğrenmek için geliştirilmiştir. DB First yaklaşımıyla veritabanı bağlantısı sağlanmıştır. Proje içerisinde üç ana form bulunmaktadır:

**Giriş Formu:** Kullanıcıların uygulamaya güvenli bir şekilde giriş yapmasını sağlar.

   ![FinancialCrmLoginForm](https://github.com/atacanguzelkaya/MyFinancialCRM/blob/master/MyFinancialCRM/Images/FinancialCrmLoginForm.png?raw=true)

**Gösterge Paneli Formu:** Veritabanındaki tablolardan gelen verileri sorgulayıp kullanıcıya sunar.
   ![FinancialCrmDashboardForm](https://github.com/atacanguzelkaya/MyFinancialCRM/blob/master/MyFinancialCRM/Images/FinancialCrmDashboard.png?raw=true)
   
**Banka Formu:** Kullanıcıların bankalardaki bakiyelerini ve son 5 banka hareketini detaylı bir şekilde gösterir.
   ![FinancialCrmBankForm](https://github.com/atacanguzelkaya/MyFinancialCRM/blob/master/MyFinancialCRM/Images/FinancialCrmBankForm.png?raw=true)

**Fatura Formu:** Fatura ekleme, listeleme, silme ve getirme işlemleri yapılmasını sağlar.
   ![FinancialCrmBillingForm](https://github.com/atacanguzelkaya/MyFinancialCRM/blob/master/MyFinancialCRM/Images/FinancialCrmBillingForm.png?raw=true)

**Teknolojiler:**
- C# (Windows Forms)
- Entity Framework
- DB First
- SQL Server
- Linq
